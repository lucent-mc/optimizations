# Lucent Optimizations

_Your game has never felt this fast before._

Lucent Optimizations is the base of all Lucent mod packs, in charge of optimizing the game, enabling us to load the game up with flavourful mods and resources.

We leverage popular optimization mods with our own configs to set ourselves up for a performant experience.

## About this Repository

This repository is set up straight from an actual instance folder within AT Launcher, that means that to keep things simple, the directory structure reflects that of an actual minecraft game.
There are some added directories that are ignored by minecraft, but useful for modrinth, like [server-overrides/](./server-overrides/) and [client-overrides/](./client-overrides/). The regular overrides folder is covered by [config/](./config/)
